# thiquoctichuc.com

Unofficial **study summary** and **practice tests** for the Australian citizenship test (**Vietnamese only**). Standalone Next.js site at [thiquoctichuc.com](https://thiquoctichuc.com), extracted from [quinstowndotcom](https://github.com/timnqp/quinstowndotcom).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Standard Next.js 15 on Vercel (or any Node host). Set environment variables from `.env.example`.
